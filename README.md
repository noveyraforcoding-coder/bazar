## 1. Project Overview

**Bazarna** is a fully-featured, multi-country e-commerce marketplace with:

- **Multi-role access** — Customer, Merchant, Country Admin, Platform Owner
- **Merchant self-service** — Product management, order tracking, wallet, shipping rates
- **Supervisor control panel** — Full admin: finance, users, analytics, KYC approvals
- **Dual payment gateway** — Paymob (Egypt) and Fawaterk (multi-region)
- **Firebase Cloud Messaging** — Real-time push notifications (web + mobile)
- **Bilingual UI** — Arabic (default) and English, powered by `django-modeltranslation`
- **Referral system**, discount vouchers, product reviews, and customer support tickets

### Core Tech Stack

| Layer | Technology |
|---|---|
| Backend Framework | Django 6.0.2 |
| Language | Python 3.12+ |
| Database | PostgreSQL 12+ (SQLite for local dev) |
| Auth | django-allauth + JWT (djangorestframework-simplejwt) |
| Static Files | WhiteNoise |
| Process Manager | Gunicorn |
| Push Notifications | Firebase Admin SDK |
| Rich Text | django-tinymce |
| i18n | django-modeltranslation |

## 4. Environment Configuration

This is the **most critical step**. The application will not start without a correctly configured `.env` file.

### Step 1 — Create the `.env` file

The repository contains a `.env` file with placeholder values. **You must replace every placeholder with your real credentials before running the application.**

Open `.env` in a text editor and fill in each value:

```env
# ==============================================================================
# CORE DJANGO SETTINGS
# ==============================================================================
SECRET_KEY=your-long-random-secret-key-replace-this-immediately
DEBUG=False
ALLOWED_HOSTS=your-domain.com,www.your-domain.com

# ==============================================================================
# DATABASE
# Format: postgres://USER:PASSWORD@HOST:PORT/DB_NAME
# ==============================================================================
DATABASE_URL=postgres://db_user:db_password@localhost:5432/bazarna_db

# ==============================================================================
# GOOGLE OAUTH 2.0
# Obtain from: https://console.cloud.google.com/
# ==============================================================================
GOOGLE_CLIENT_ID=your-google-oauth-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-google-oauth-client-secret

# ==============================================================================
# PAYMOB PAYMENT GATEWAY (Egypt)
# Obtain from: https://accept.paymob.com/portal2/en/settings
# ==============================================================================
PAYMOB_API_KEY=your-paymob-api-key
PAYMOB_INTEGRATION_ID_CARD=your-paymob-card-integration-id
PAYMOB_INTEGRATION_ID_WALLET=your-paymob-wallet-integration-id
PAYMOB_IFRAME_ID=your-paymob-iframe-id

# ==============================================================================
# FAWATERK PAYMENT GATEWAY (Multi-region)
# Obtain from: https://fawaterk.com/
# ==============================================================================
FAWATERK_API_KEY=your-fawaterk-api-key
FAWATERK_SUCCESS_URL=https://your-domain.com/my-orders/
FAWATERK_WEBHOOK_URL=https://your-domain.com/payment/callback/
```

> [!IMPORTANT]
> **Never commit your `.env` file.** It is already listed in `.gitignore`. Verify this before pushing to any repository.

### Step 2 — Add Firebase Credentials

Place your Firebase service account JSON file at the **project root**, named exactly:

```
firebase-key.json
```

Obtain this file from the Firebase Console:
**Project Settings → Service Accounts → Generate New Private Key**

> [!CAUTION]
> `firebase-key.json` contains sensitive credentials. Ensure it is listed in `.gitignore` and is **never** committed to version control.

### Step 3 — Create the PostgreSQL Database

```sql
CREATE DATABASE bazarna_db;
CREATE USER db_user WITH PASSWORD 'db_password';
GRANT ALL PRIVILEGES ON DATABASE bazarna_db TO db_user;
```

## 5. Installation

### Step 1 — Clone the Repository

```bash
git clone https://github.com/your-org/bazarna.git
cd bazarna
```

### Step 2 — Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it:

- **Windows:** `.venv\Scripts\activate`
- **macOS / Linux:** `source .venv/bin/activate`

### Step 3 — Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4 — Run Database Migrations

```bash
python manage.py migrate
```

### Step 5 — Create the Cache Table

```bash
python manage.py createcachetable
```

### Step 6 — Collect Static Files

```bash
python manage.py collectstatic --noinput
```

### Step 7 — Create a Superuser

```bash
python manage.py createsuperuser
```

Follow the prompts to set your admin username, email, and password.

## 6. Running Locally

```bash
python manage.py runserver
```

The development server will start at: [http://127.0.0.1:8000](http://127.0.0.1:8000)

| Panel | URL |
|---|---|
| Customer Storefront | `http://127.0.0.1:8000/` |
| Django Admin | `http://127.0.0.1:8000/ar/admin/` |
| Supervisor Panel | `http://127.0.0.1:8000/ar/super/` |
| Merchant Panel | `http://127.0.0.1:8000/ar/merchant/` |

> **Note:** All routes are prefixed with a language code (`/ar/` or `/en/`). The default language is Arabic.

## 7. Key Configuration Notes

### Payment Gateways

| Gateway | Region | Production URL |
|---|---|---|
| Paymob | Egypt (EGP) | `https://accept.paymob.com` |
| Fawaterk | Multi-region | `https://app.fawaterk.com/api/v2` |

Each gateway's credentials must be configured in the `.env` file as described in Section 4. The active gateway per country is configurable from the Supervisor Panel → Site Settings.

### Multi-Country Configuration

Countries, currencies, and payment gateway assignments per country are managed through the Django admin or Supervisor Panel. Add at least one **active Country** and assign it to users and products before testing checkout flows.

### Internationalization

The application defaults to Arabic (`ar`). To switch the UI language, navigate to:
- `/i18n/setlang/` (POST with `language=en` or `language=ar`)

Translation files are located in `locale/`. After modifying `.po` files, compile them with:

```bash
python manage.py compilemessages
```

### Internal Documentation Viewer

The endpoint `/ar/dev-docs/<doc_name>/` renders internal Markdown documentation and is **restricted to superusers only**. It will return a 404 for all other users.

## 8. Deployment

The project includes a `Procfile` for Heroku-compatible platforms:

```
web: gunicorn bazarna.wsgi --log-file -
```

### Environment Checklist for Production

Before deploying to production, ensure:

- [ ] `DEBUG=False` in `.env`
- [ ] `SECRET_KEY` is a long, random, unique string (minimum 50 characters)
- [ ] `ALLOWED_HOSTS` lists only your production domain(s)
- [ ] `DATABASE_URL` points to your production PostgreSQL instance
- [ ] All payment gateway keys are production (non-sandbox) credentials
- [ ] `FAWATERK_SUCCESS_URL` and `FAWATERK_WEBHOOK_URL` use your real domain
- [ ] `collectstatic` has been run
- [ ] `firebase-key.json` is deployed securely (not committed to git)
- [ ] HTTPS is enforced at the load balancer / reverse proxy level
